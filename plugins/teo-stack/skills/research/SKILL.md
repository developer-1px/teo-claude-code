# Research

The requester will act on this, often by handing it to another agent. You already
know how to search, read primary sources, and cite. This skill only sets what the
result must do so that the next step can start from it.

1. **Why first.** From the requester's words, infer the decision or change this
   feeds. Research only the items whose answer could change that action, and say
   so at the top.
2. **as-is → to-be, and why.** For each relevant competitor or reference, show what
   changed (with version or date) and why they chose the new form, their own stated
   reason first. From the shared reasons, name the convergence direction and how
   settled it is; one vendor is a case, not convergence.
3. **Actions.** Close with action items for us: what to change, where, the first
   step, and how we will know it worked, each tied to a change above. Write them so
   an agent can start without rereading the sources.
4. **Show it.** Put a before/after image or a diagram beside each case, and one for
   the convergence, with a caption naming what to look at and the source.

Write plainly. State conclusions; mention a limitation only where it would change
an action.

Order: 왜 이 리서치를 하나 → 결론 → 사례 → 수렴 방향 → 액션 아이템 → 출처.
